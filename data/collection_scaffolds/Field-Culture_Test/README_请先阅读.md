# Field-Culture_Test 采集与标注包（未采集）

此包包含 600 项预分配任务，30 个预留说话者编号。它不是已完成的真实语音数据集。没有录音、人工转写、真实参与者资料或实测环境噪声。所有情境提示为程序生成的采集材料，不是参与者发言。不得以本包声称已开展参与者研究或模型实测。

samples.jsonl 包含每条任务的情境提示、预定任务类别、音频目标路径及生成任务字段。samples.csv 为简化索引。speakers.csv 中年龄、同意状态和身份去重信息均待采集。预定类别不等于实测意图标签；采集后按实际表达由人工标注。请让成年参与者自行组织语言，不要朗读情境提示。

录音使用48 kHz、24位、单声道PCM WAV；保留原始文件，再通过低通抗混叠重采样转换为16 kHz、16位、单声道PCM WAV。禁止仅修改文件头。audio/raw 与 audio/16k 仅保留路径说明，没有占位伪音频。

采集前完成适用的知情同意、隐私和使用授权手续。真实身份映射应单独受控保存，不放入发布包。将音频填入指定路径，人工转写填入transcript，实际意图填入cultural_intent_label，并更新状态与清单。历史故事参考需由专家核实人物、时代、地域、工艺和文化内涵，避免虚构历史事实。古诗参考仅覆盖四首公版诗词，采集前应按研究需要扩充；创作性续写不应以原诗接续作为唯一正确答案。

CSSP按预留编号划分36/12/12名说话者，每人80项任务。Field-Culture Test每场景10名，每人20项，仅用于测试。编号互异不能证明真实人员无重叠，招募时必须核实。Field采集使用相同设备，距离约30–50厘米；保留背景人声、混响和正常环境噪声，并记录实测条件。

validation.json 校验的是任务配置与编号，不是音频质量或参与者真实性。
